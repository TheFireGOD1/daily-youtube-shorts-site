Privacy

Privacy policy

Effective October 13, 2026

Daily YouTube Shorts is a personal tool operated for the owner of one YouTube channel. It is not offered to the public and has no third-party users.

Information used

  • Google OAuth credentials authorize access to the owner's YouTube channel for reading recent uploads and uploading generated videos. Credentials are stored as encrypted GitHub Actions secrets.
  • A short voice reference supplied by the channel owner is encrypted in the private source repository. It is temporarily decrypted on an isolated cloud runner to synthesize narration, then removed when that run ends.
  • Public articles from a fixed set of primary-source feeds are used to prepare scripts and citations. The tool does not collect information about viewers.

How information is used and shared

Information is used only to create, render, and upload the owner's videos. The tool does not sell personal information or share it with advertisers. Script generation, voice synthesis, Blender rendering, and audio mixing run on the temporary GitHub-hosted runner; no paid third-party generation service is used.

Storage and retention

OAuth credentials stay in GitHub Actions secrets. The encrypted voice reference stays in the owner's private repository. Generated scripts, source links, videos, and run status may be retained as a private workflow artifact for up to seven days. Uploaded videos follow the visibility chosen by the channel owner and remain subject to YouTube's own policies and controls.

Choices and deletion

The channel owner can disable the workflow, delete its GitHub secrets or encrypted voice file, delete workflow artifacts, and revoke the Google authorization from the Google Account security settings. No video is uploaded when a required credential or processing step is missing.

Changes and contact

This policy may be updated when the tool's data handling changes. For questions, use the support email shown on the Google OAuth consent screen for Daily YouTube Shorts.
